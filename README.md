# Banking Customer Analytics and Fraud Detection System

An end-to-end Banking Analytics and Fraud Detection project built using Python, MySQL, Machine Learning, and Power BI to analyze 1,048,576 credit card transactions and generate actionable business insights for fraud monitoring, customer behavior analysis, and executive reporting.

---

## Project Overview

This project simulates a real-world banking analytics environment by analyzing large-scale transaction data to:

- Detect fraudulent transactions
- Analyze customer spending behavior
- Monitor revenue trends
- Identify high-risk transaction categories
- Generate executive-level dashboards
- Deliver strategic business insights

The project demonstrates practical applications of:
- Data Analytics
- Fraud Detection
- Business Intelligence
- Dashboard Reporting
- Customer Segmentation
- Financial Data Analysis

---

## Dataset Used

Dataset Source:  
[Credit Card Transactions Dataset - Kaggle](https://www.kaggle.com/datasets/priyamchoksi/credit-card-transactions-dataset)

## Key Business Insights

- Grocery and shopping categories generated the highest revenue.
- Fraud activity increased significantly during late-night hours.
- Online shopping categories showed higher fraud probability.
- Middle-aged customers contributed the highest revenue share.
- Geographic fraud patterns highlighted high-risk transaction regions.
